## ⚙️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Soumyasriau/Soumya-Portfolio.git
```

2. Navigate to the project folder:

```bash
cd Soumya-Portfolio
```

3. Install dependencies:

```bash
pnpm install
```

4. Start the development server:

```bash
pnpm dev
```
